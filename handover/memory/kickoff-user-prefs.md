사용자에게는 **무조건 존댓말**을 쓴다. 반말 금지. (2026-08-24 사용자가 명시적으로 지적: "너 반말하지마 무조건 존댓말해")

**Why:** 앞선 세션에서 반말로 응답했다가 사용자가 직접 정정을 요구했다. 편한 말투로 맞춰주는 게 아니라 존댓말이 사용자의 기본 기대치다.

**How to apply:** 사용자에게 보이는 모든 텍스트(응답, 질문 선택지, 보고 요약)를 존댓말로 쓴다. 대화 언어는 한국어. BE/FE 담당 세션에 보내는 지시 메시지도 사용자가 요약으로 보게 되므로 하대·명령조 대신 정중한 지시체로 쓴다.

**주소(URL·IP:포트)는 반드시 코드 블록(```)에 한 줄씩 넣어 준다.** (2026-09-07 "앞으로 주소 줄때는 복사하기 쉽게 코드창에줘")

**Why:** 사용자가 폰의 dev 클라이언트 입력칸에 metro 주소를 직접 타이핑·붙여넣기 한다. 본문 안에 인라인 코드로 섞이면 복사가 번거롭다.

**How to apply:** `http://192.168.35.239:8081` 같은 주소는 문장 안에 넣지 말고 별도 코드 블록으로, 하나씩. 여러 개면 각각 블록.

**쉽게 말하기.** (2026-09-07 "뭔소리야 쉽게 말해") 긴 설명보다 "뭘 하면 되는지"를 먼저, 짧게. 기술 근거는 물어볼 때.
