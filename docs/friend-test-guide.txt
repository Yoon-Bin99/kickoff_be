⚽ 킥오프(Kickoff) 테스트 부탁해!

조기축구 팀 매칭 앱을 만들고 있는데, 한번 써보고 솔직한 의견 부탁해.
(안드로이드만 가능, 아이폰은 아직!)

📲 설치 (1분)
1. 아래 링크를 폰에서 열기
   https://expo.dev/artifacts/eas/ZT678ewYdrYJEzUSaZpPyGTDVaWq8znXUeXAxtpl848.apk
2. APK 다운로드 → 열기 → "출처를 알 수 없는 앱" 경고 나오면 [무시하고 설치] 또는 [설정에서 허용]
   (구글에 등록 안 된 테스트 앱이라 뜨는 정상 경고야)
3. 설치된 "Kickoff" 실행

🔑 시작하기
- 카카오나 네이버로 바로 로그인 가능 (회원가입 필요 없음)
- 이메일 가입도 됨

🕹️ 이런 거 해봐줘
1. 홈에서 모집글 구경 — 상단에서 지역 바꿔보기
2. 팀 이름 눌러서 팀 페이지 구경 (별점, 전적, 선수 명단)
3. "팀 만들기"로 너네 팀 등록해보기 (팀 컬러도 골라봐)
   - 하단 "팀" 탭에서 다른 팀 검색해서 가입 신청도 가능 (감독이 수락하면 팀원!)
4. 모집글 하나 써보기 — 장소는 검색해서 고르면 지도에 뜸
5. 아무 글에나 매칭 신청 걸어보기
6. 매칭이 성사되면 상대 팀 감독이랑 채팅 가능 — 하단 "채팅" 탭
7. 모집글 공유 버튼으로 카카오톡 단톡방에 카드 보내보기
8. 매칭되면 입금 안내에서 "토스로 송금" 눌러보기 (진짜 이체 직전까지만!)

💬 듣고 싶은 것
- 어디서 막혔는지 / 뭐가 불편했는지
- "이런 기능 있으면 쓰겠다" 싶은 것
- 솔직하게! 아직 다듬는 중이라 쓴소리가 제일 도움 됨

⚠️ 참고
- 테스트 서버라 데이터는 나중에 초기화될 수 있음
- 매칭이 수락되면 서로 연락처가 공개되는 구조야 (실제 번호 넣기 싫으면 아무 010 번호나 OK)
- 앱에 이미 있는 글/계좌는 가짜 테스트 데이터야 — 토스에서 진짜 이체 버튼까진 누르지 마!
- 카카오톡 공유 카드의 "앱에서 보기" 버튼은 앱 설치한 사람만 열려 (아직 스토어에 없어서)
- 태블릿의 분할 키보드에서는 채팅 입력창이 가려질 수 있어 — 표준 키보드면 정상
