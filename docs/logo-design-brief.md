# 킥오프(Kickoff) 로고·앱 아이콘 디자인 요청서

## 서비스 소개
- **이름**: 킥오프 (Kickoff)
- **무엇**: 조기축구 팀 매칭 앱 — 아마추어 축구팀끼리 "이번 주말 우리랑 한 판 붙을 팀"을 찾아주는 서비스
- **사용자**: 20~50대 아마추어 축구팀 주장·총무. 매주 이른 아침 공터·구장에서 공을 차는 사람들
- **분위기**: 이른 아침의 상쾌함, 아마추어의 진심, 동네 축구의 정겨움. 프로 구단 엠블럼처럼 무겁지 않게

## 브랜드 컬러 (확정)
- **메인**: 잔디 그린 `#1B7F4B`
- 보조 색은 자유 제안 (새벽 하늘, 일출 주황, 흰 라인 등 어울리는 방향 환영)

## 산출물 (필수)
1. **앱 아이콘** — 1024×1024, 여백 포함 정사각. iOS(모서리 라운딩은 OS가 적용)와 Android 겸용
2. **Android 어댑티브 아이콘 전경** — 1024×1024, 중앙 안전 영역(지름 66%) 안에 핵심 요소 배치, 배경은 단색(#1B7F4B 또는 제안 색) 분리
3. **스플래시 화면 로고** — 세로 화면 중앙에 놓일 로고+워드마크 조합 (배경색 지정 포함)
4. **로그인 화면용 로고** — 워드마크("킥오프" 또는 "Kickoff") 포함 가로형

## 디자인 조건
- **60px(홈 화면 실제 크기)에서도 또렷해야 함** — 가는 선·작은 글자·복잡한 디테일 금지
- 텍스트 없는 심벌만으로 아이콘이 성립해야 함 (워드마크는 스플래시·로그인용)
- 유행 타는 그라데이션 과용 지양, 단순하고 오래갈 형태

## 참고 — 내부 시안 방향 4가지 (이 중에서 발전시켜도, 새로 제안해도 좋음)
1. **새벽 공**: 지평선 위 일출 + 축구공. '조기'축구의 시간대를 담음
2. **K 모노그램**: K자의 아래 획이 공을 차는 다리 형태
3. **하프라인 매칭**: 하프라인을 두고 마주 선 두 팀 — 앱의 본질(매칭)을 표현
4. **킥오프 휘슬**: 심판 휘슬 실루엣 — 이름의 직역, 작은 크기에서 가장 또렷

기존 시안 파일: `kickoff_fe/assets/logo-drafts/01~04-*.svg`

## 납품 형식
- 각 산출물 SVG(원본) + PNG(위 규격)
- 아이콘은 밝은 배경/어두운 배경 각각에서 확인된 상태로
